منصتك التعليمية
================

ملفات المشروع الأولية:
- index.html              الواجهة الرئيسية
- firebase-config.js      إعدادات Firebase المرسلة للمشروع
- device.js               معرف الجهاز ومنع التكرار (مساعد)
- image-upload.js         نظام رفع الصور إلى ImgBB

ملاحظة:
النسخة الحالية هي نسخة تجريبية للواجهة والوظائف. الربط النهائي مع Firestore وقواعد الصلاحيات يحتاج استكمال إعداد قواعد Firebase قبل النشر الإنتاجي.
